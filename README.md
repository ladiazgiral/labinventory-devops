## Descripción

LabInventory API es una aplicación desarrollada con Django y Django REST Framework que permite administrar equipamiento tecnológico de laboratorio mediante operaciones CRUD.

El proyecto forma parte de una implementación DevOps que incorpora control de versiones, pruebas automatizadas, contenerización con Docker, integración continua, entrega continua y despliegue en AWS.
